# Horizon Workbench

A supported beta showcase for Horizon splits, tabs, workspaces, responsive layout, floating windows, and window chrome.

```bash
pnpm demo:horizon
```

Press `1`-`3` to switch workspaces, `[` and `]` to resize the split, `i` for the inspector, `m` to maximize or restore it, `Ctrl+P` for commands, and `q` to quit.
