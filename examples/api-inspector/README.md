# API Inspector

A supported Celestial preview demo backed by an ephemeral HTTP server bound to `127.0.0.1`. It never contacts an external service.

```bash
pnpm demo:api
```

The default request is `GET /health`. Press `s` or `Ctrl+Enter` to send, `Tab` to move between controls, `h` for history, `r` to reset, and `q` to quit.
